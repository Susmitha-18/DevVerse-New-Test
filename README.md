# DevVerse

> **Build • Deploy • Monitor • Learn**

An AI-powered Developer & DevOps Platform built for modern engineering teams.

---

## Overview

DevVerse is a hybrid application platform that combines a powerful **Desktop Application**, a robust **Backend API**, and a public **Landing Website** into a single cohesive product.

| Application | Technology | Description |
|-------------|-----------|-------------|
| `desktop/`  | Electron + React + TypeScript + Vite + Tailwind CSS | Main product — desktop client |
| `backend/`  | Node.js + Express + TypeScript + MongoDB Atlas | REST API + Auth + Business Logic |
| `website/`  | React + TypeScript + Vite + Tailwind CSS | Public landing page |

## Getting Started

### Prerequisites

- Node.js >= 20.x
- npm >= 10.x
- Git

### Clone the Repository

```bash
git clone https://github.com/your-org/devverse.git
cd devverse
```

### Install All Dependencies

```bash
npm install
```

### Run the Backend

```bash
npm run dev:backend
```

### Run the Desktop App

```bash
npm run dev:desktop
```
