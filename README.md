# DevVerse

AI-powered Developer & DevOps Platform. Manage container builds, deployments, repository pipelines, and monitoring stats with direct Google Gemini AI feedback.

---

## 🚀 Features

*   **Authentication:** Local registration/login secured with custom JWT token exchange and GitHub OAuth authorization.
*   **GitHub Integration:** Sync repositories, scan active branches, and list commit history records.
*   **Docker Integration:** Build container images locally, pull images, push to registries, and manage host engine caches.
*   **CI/CD Integration:** Sync with GitHub Actions workflows, view run logs, and track execution steps.
*   **AWS Deployment:** Orchestrate deployments to virtual machines (AWS EC2 instances) with one-click status rollbacks.
*   **Monitoring & Observability:** Track server metrics and CPU/RAM consumption via Prometheus scraping and Grafana dashboards.
*   **AI Assistant:** Powered by Google Gemini. Instantly explain compilation and run-time errors, generate Dockerfiles, write GitHub actions workflows, and summarize build logs.

---

## 🛠️ Tech Stack

*   **Frontend:** React, TypeScript, Tailwind CSS, Vite
*   **Backend:** Node.js, Express.js
*   **Database:** PostgreSQL
*   **DevOps:** Docker, GitHub Actions, AWS EC2
*   **Observability:** Prometheus, Grafana
*   **AI Support:** Google Gemini API
