# Technology Stack

This document outlines the tech stack used for building **DevVerse**, an AI-powered Developer & DevOps Platform.

## Frontend
*   **Library:** React
*   **Language:** TypeScript
*   **Styling:** Vanilla CSS (or Tailwind CSS if configured)
*   **Build Tool:** Vite

## Backend
*   **Runtime:** Node.js
*   **Framework:** Express.js
*   **Language:** TypeScript / JavaScript

## Database
*   **Database Engine:** PostgreSQL
*   **ORM/Query Builder:** Prisma or pg pool (direct SQL)

## Authentication
*   **Tokens:** JSON Web Tokens (JWT)
*   **OAuth:** GitHub OAuth for seamless developer registration and integration

## Containerization & DevOps
*   **Containerization:** Docker
*   **Orchestration/Engine:** Docker Engine / Docker Compose (local development)

## CI/CD
*   **Automation:** GitHub Actions for building, testing, and triggering deployment workflows

## Cloud Hosting & Deployment
*   **Hosting:** AWS EC2 (Virtual Machine Instance)
*   **Web Server / Reverse Proxy:** NGINX

## Monitoring
*   **Metrics Gathering:** Prometheus
*   **Data Visualization:** Grafana

## AI Integration
*   **AI Model Provider:** Google Gemini API
*   **Use Cases:** Explaining system/build errors, Dockerfile generation, GitHub Action workflow generation, and Log summarization.
